# Marketplace icons

These locally stored icons appear as linked identifiers in the repository README. Local copies avoid image hotlinks from third-party marketplaces.

- `skills-sh.png` — Skills.sh official site favicon, converted from ICO to PNG: <https://www.skills.sh/favicon.ico?favicon.3fpu2ql9ns1a0.ico>
- `agensi.png` — Agensi logo asset from its NestJS Skills listing page, converted from WebP to PNG: <https://www.agensi.io/agensi-logo-256.webp>
- `skillstore.svg` — Skillstore icon from its official site: <https://skillstore.io/skillstore-icon.svg>

Retrieved 2026-10-06. Marketplace names and marks belong to their respective owners; each icon links to a NestJS Skills listing on that marketplace.
