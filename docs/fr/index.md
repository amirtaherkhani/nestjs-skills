## Par où commencer ?

Le [guide de démarrage](./guide/getting-started) explique comment installer la collection et choisir une compétence. Les guides techniques détaillés restent en anglais ; chaque carte mène directement au guide correspondant.

### Une démarche d’ingénierie cohérente

Les compétences partagent les mêmes principes : examiner le dépôt réel, respecter les contrats existants, choisir la solution sûre la plus simple et vérifier le résultat par des tests ou des mesures. Chacune a un périmètre précis et passe le relais lorsque le travail l’exige.

Pour un changement important, commencez par clarifier les frontières du système, puis les responsabilités des objets, et enfin les fonctions NestJS et les vérifications nécessaires.

## Installer la collection

Le format ouvert Agent Skills fonctionne avec Claude Code, Codex et les outils compatibles :

```bash
npx skills add amirtaherkhani/nestjs-skills
```

Consultez le [guide de démarrage](./guide/getting-started) pour installer un seul skill et découvrir les commandes utiles.
