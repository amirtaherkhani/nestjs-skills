## NestJS Skills چیست؟

NestJS Skills مجموعه‌ای متن‌باز از هفت Agent Skill برای عامل‌های کدنویسی مانند Claude Code و Codex است. این مهارت‌ها به عامل‌ها کمک می‌کنند کدبیس NestJS را بشناسند، تغییرهای مهندسی و معماری را هدفمند انجام دهند، کد را بازبینی کنند و رفتار زمان اجرا را بسنجند.

## از کجا شروع کنم؟

اگر برای نخستین بار از این مجموعه استفاده می‌کنید، [راهنمای شروع به کار](./guide/getting-started) روش نصب و انتخاب مهارت را توضیح می‌دهد. هر هفت راهنمای فنی کامل فعلاً به انگلیسی هستند؛ پیوند هر کارت شما را مستقیم به راهنمای انگلیسی همان مهارت می‌برد.

### یک جریان کاری منسجم

مهارت‌ها بر چند اصل مشترک تکیه می‌کنند: ابتدا مخزن واقعی را بررسی کنید، قراردادهای موجود را حفظ کنید، ساده‌ترین طراحی ایمن را برگزینید و نتیجه را با آزمون یا اندازه‌گیری بسنجید. هر مهارت مسئولیت مشخصی دارد و هنگام نیاز کار را به مهارت بعدی می‌سپارد.

برای تغییرهای بزرگ، از مهندسی نرم‌افزار برای هماهنگی استفاده کنید: ابتدا مرزهای سیستم را روشن کنید، سپس همکاری اشیا و در پایان ویژگی‌های زمان اجرای NestJS و شیوهٔ راستی‌آزمایی را انتخاب کنید.

## نصب مجموعه

این قالب باز و استاندارد برای Claude Code، Codex و ابزارهای سازگار با Agent Skills کار می‌کند:

```bash
npx skills add amirtaherkhani/nestjs-skills
```

برای دیدن مراحل نصب و دستور انتخاب یک مهارت، [راهنمای شروع به کار](./guide/getting-started) را بخوانید.
